# Tsensei Robot

**Dexterity that scales.**

Tsensei Robot develops high-performance, liquid-cooled,
direct-drive dexterous hands for humanoid robotics
and Physical AI.

Our focus is on making dexterous manipulation more
capable, reliable, and accessible.
